# 이전 결과의 사용 중단

저장된 API 응답 1,000개 모두 waypoint 배열이 없었고, 원본 파서는
기본값 [[0,0],[0,0]]을 반환했다. 필터링과 endpoint 자동 삽입 후에는
모든 사례의 llm_output이 [start, goal]이었다.

따라서 이 결과는 정상적인 LLM 경유점 안내 효과를 재현한 결과로
사용하지 않는다. 당시 탐색의 휴리스틱은 target=goal이므로
g+2*distance_to_goal 형태였다. 기록은 디버깅/실패 분석을 위해 보존한다.

수정 실험은 ../reproduction_v2/에서 수행하며, 설치만으로 완료를 주장하지 않는다.
